# جدول جلسات أ. رنا

موقع محلي أحادي الصفحة صُمّم لتستخدمه أ. رنا نفسها لإنشاء جدول الجلسات والصورة النهائية.

## التدفق
1. الشهر والسنة من تاريخ الجهاز تلقائياً، مع إمكانية التعديل.
2. اختيار أيام الجلسات من السبت إلى الخميس.
3. اختيار وقت موحد أو وقت مختلف لكل يوم، بنظام AM / PM.
4. مراجعة كل المواعيد وتعديلها أو حذفها أو إضافة موعد يدوياً.
5. إنشاء صورة نهائية مطابقة بصرياً للمرجع مع الشهر والسنة والمواعيد الجديدة.
6. تنزيل الصورة بصيغة PNG عالية الدقة.

لا يوجد مسار «إرسال للمراجعة» لأن أ. رنا هي المستخدمة الفعلية للموقع.
